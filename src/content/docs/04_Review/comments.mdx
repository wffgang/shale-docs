Shale's comment system ties written feedback directly to a position and camera angle in the scene, so reviewers can always see exactly what a note refers to.

## Creating a comment

Double click anywhere in the review environment to place a spatial note. Notes can contain:

- Written text
- Drawn annotations (via the brush engine)

Other options include:
- "C" Key to enter comment mode
- Comment icon via toolbar at the top of the UI
- Right click to bring up options to create and delete note

## Go-to context view

Every comment stores the **exact camera position** at the time it was created — no hunting around the scene.
- Via Web interface: click on any note to jump back to that view instantly
- Via Plugin interface: click on view & render options on any note to jump back to the view

## Comment threads

Comments support threaded replies, so conversations stay attached to the relevant scene location rather than drifting into external chat tools.
- Via Web interface: click on any note to view all threaded comments
- Via Plugin interface: expand on any note to view all threaded comments

## Approval states

Comments can be marked with approval states (e.g. **Open**, **Resolved**) to track progress through a review cycle.
